🎓 ScholarHub Demo Script

Fullstack Next.js + Django + FastAPI Presentation

Scene 1: Introduction

0:00 - 0:30
Screen Action
Show the ScholarHub Login page.
What to say

"Hi everyone, this is my Fullstack School Management mini-project called ScholarHub. It’s built using Next.js for the frontend, Django for the backend database, and FastAPI for an AI microservice. Notice that the page is completely clean, and the navigation bar is hidden because we are not logged in yet. Let me show you the secure authentication flow."

Scene 2: Auth & Protected Routes

0:30 - 1:00
Screen Action
Click "Sign up" (create a quick test user if needed), then Log in.
What to say

"I'll log in using JWT Authentication. Once authenticated, Next.js saves a secure token in local storage and redirects me to the Dashboard. If I try to access the students URL without logging in, the layout acts as a bouncer and kicks me back to the login screen."

Scene 3: The Dashboard & Stats

1:00 - 1:30
Screen Action
Hover over the stats cards on the Dashboard.
What to say

"This is the Admin Dashboard. The statistics here—Total, Male, and Female students—are not hardcoded. They are being calculated in real-time by Django using database queries and sent via a secure API. This ensures high performance."

Scene 4: Students List & Search

1:30 - 2:00
Screen Action
Click "Students" in the Navbar. Type "haw" into the search bar.
What to say

"Here is the student directory. We have a responsive Tailwind grid. Watch this—I can search by name and the list filters instantly. Next.js handles this efficiently in the frontend state."

Scene 5: Full CRUD Operations

2:00 - 2:45
Screen Action
Click "Add Student", fill out the form, save. Click "Edit", change the age, save. Click "Delete".
What to say

"The app features full CRUD. I can add a new student—which posts directly to the Django REST API. Then I can view their profile, edit their details—notice the form is pre-filled—and save. Finally, I can delete the student, which safely removes them from the Django database."

Scene 6: The AI Microservice

2:45 - 3:15
Screen Action
Open a student profile and click "✨ Generate AI Report". Wait for the purple box.
What to say

"Here is the AI feature. When I click this button, Django fetches this student's data and securely passes it to a separate FastAPI Python microservice. FastAPI analyzes the data and generates a custom report, which is then sent back to the frontend."

Scene 7: Backend Security

3:15 - 3:45
Screen Action
Switch to Django Admin tab. Then open a new tab to the raw API URL (e.g., /api/students/).
What to say

"To prove this is production-ready, here is the Django Admin panel where all data is stored. And if I try to access the raw API endpoint without a token, Django blocks it with a 401 Unauthorized error. My database is completely secure."

Scene 8: Conclusion

3:45 - 4:00
Screen Action
Go back to the Dashboard.
What to say

"That is ScholarHub. It demonstrates secure authentication, relational databases, microservice architecture, and a polished UI. Thank you for watching!"

💡 Pro-Tips for Recording

  • Use Loom.com (it's free and gives you a camera bubble if you want).
  • Zoom your browser to 100% or 110% so the text is readable on video.
  • Speak slowly and confidently. Don't worry if you make a mistake, just pause and keep going.
  • Don't rush the clicks. Let the viewer see the page load before you click the next thing.
  • Upload to YouTube (unlisted) and add the link to your CV or GitHub README!
